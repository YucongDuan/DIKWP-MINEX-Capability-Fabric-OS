## Launch demonstration

Publish three reproducible comparisons:

1. model-native vs deterministic local code for document profiling;
2. API vs GUI for the same functional unit;
3. local node vs same-owner peer vs paid provider under different privacy and time budgets.

For every comparison publish:

```text
intent
catalog
hard gates
all candidate routes
Pareto frontier
selected route
measurement source
execution receipt
limitations
```

## Adoption loop

```text
user declares outcome
→ MINEX exposes avoidable app/model cost
→ route receipt is shared in an issue or PR
→ provider publishes a better capability manifest
→ new route becomes available
→ community reproduces the comparison
```
